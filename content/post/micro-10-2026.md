
provides decent formatting.<br>
<a href="#" style="text-decoration: none;">2026-10-14</a>: [Making git hooks
visible](https://nedbatchelder.com/blog/202610/making_git_hooks_visible): I
don't have that many Git hooks for my own repos but this looks like a good idea.
I'm already using a Zsh hook to detect uv virtual environments:

```shell
function auto_activate_venv() {
  if [ -f ".venv/bin/activate" ]; then
    source .venv/bin/activate
  fi
}

autoload -U add-zsh-hook
add-zsh-hook chpwd auto_activate_venv
```
