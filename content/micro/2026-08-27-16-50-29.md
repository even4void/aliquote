> "Modern" is quite a buzzword, but it is justified when talking about Neovim.
The project started as a big refactoring of the Vim codebase, throwing away a
lot of code and removing support for legacy systems. It uses a brand new VimL
parser which is much faster than Vim's one, leverages libuv for asynchronous IO
and is generally much more modular. --- [Why Neovim over
Vim](https://cbarrete.com/neovim.html)
